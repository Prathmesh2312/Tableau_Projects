# HR Dashboard - Tableau Project

## 📊 Project Overview

The **HR Dashboard** is a comprehensive Tableau visualization project designed to support HR managers in making data-driven decisions. It provides both **summary insights** and **detailed employee records**, helping stakeholders monitor workforce composition, analyze employee demographics, and identify trends in salary and performance.

---

## 👤 User Story

> As an HR manager, I want a comprehensive dashboard to analyze human resources data, providing both summary views for high-level insights and detailed employee records for in-depth analysis.

---

## 🔍 Features

### 🔹 Summary View

The Summary View is divided into **three main sections**:

#### 1. Overview
- Total number of **hired**, **active**, and **terminated** employees.
- Year-wise trend of **hiring** and **terminations**.
- Employee distribution by **department** and **job titles**.
- Comparison of employees at **HQ (New York)** vs **other branches**.
- Employee distribution by **city** and **state**.

#### 2. Demographics
- Gender ratio across the company.
- Distribution across **age groups** and **education levels**.
- Count of employees per **age group** and **education level**.
- Correlation between **education** and **performance ratings**.

#### 3. Income Analysis
- Salary comparison across **education levels** by **gender**.
- Correlation between **age** and **salary** within departments.

---

### 🔸 Employee Records View

A detailed, filterable table that includes:
- Employee **Name**, **Department**, **Position**
- **Gender**, **Age**, **Education**, **Salary**

Users can filter and sort by any available column for custom analysis.

---

## 🛠️ Tools Used

- **Tableau** for data visualization
- **HR dataset** (synthetic or anonymized for privacy)

---

## 📁 How to View

To explore the dashboard:

1. Download the `.twbx` file from this repository.
2. Open it using [Tableau Desktop](https://www.tableau.com/products/desktop) or Tableau Public.
3. Interact with the views to explore the HR metrics and employee data.
